# Nova-Super-Star-Trek
Super Star Trek for Data General Nova Extended BASIC.

Probably requires 32 kW, but may run on 24 kW (if not then try to delete the instructions at the end).

IMPORTANT: For uploading under Extended BASIC, you must use a transmit delay of at least 2 msec/char and 100 msec/line. In Tera Term, this is specified under Serial port.
